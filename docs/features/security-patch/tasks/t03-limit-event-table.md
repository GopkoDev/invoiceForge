## Data delta

| Column | Type | Constraints | Change |
|---|---|---|---|
| `id` | TEXT | PK, `cuid()` | added |
| `scope` | `"LimitScope"` enum (`SIGNIN_SOURCE`, `SIGNIN_ADDRESS`, `EXPORT`) | NOT NULL | added |
| `key` | TEXT | NOT NULL | added |
| `outcome` | `"LimitOutcome"` enum (`REQUESTED`, `SENT`, `REFUSED`, `ALERTED`, `STARTED`, `FAILED`) | NOT NULL | added |
| `at` | TIMESTAMP(3) | NOT NULL DEFAULT CURRENT_TIMESTAMP | added |
| `userId` | TEXT | NULL, FK → `User(id)` ON DELETE CASCADE ON UPDATE CASCADE | added |

Indexes: `LimitEvent_pkey (id)`, `LimitEvent_scope_key_at_idx (scope, key, at)`, `LimitEvent_at_idx (at)`, `LimitEvent_userId_idx (userId)`.

```prisma
model LimitEvent {
    id      String       @id @default(cuid())
    scope   LimitScope
    key     String
    outcome LimitOutcome
    at      DateTime     @default(now())
    userId  String?

    user User? @relation(fields: [userId], references: [id], onDelete: Cascade)

    @@index([scope, key, at])
    @@index([at])
    @@index([userId])
}
// and on User:  limitEvents LimitEvent[]
```
